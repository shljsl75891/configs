- Tests in `pi/extensions/*` import pi packages through a `node_modules` symlink to the installed pi release. Before you run tests, check that the symlink resolves to the current release, which is listed in `pi/install/current-version`. If it does not, run `ln -sfn ../../install/releases/$(cat pi/install/current-version)/node_modules pi/extensions/<ext>/node_modules`. Run tests with `node --test <file>.test.ts`.
